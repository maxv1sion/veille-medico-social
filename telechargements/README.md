# Téléchargements

`JO/AAAA-MM-JJ/` : textes du Journal officiel retenus pour la veille, classés par date de publication.

Pour chaque texte :
- `JORFTEXT….txt` : version lisible (intitulé, dates, NOR, lien Légifrance, visas, articles, signataires)
- `JORFTEXT….xml` : fichier officiel d'origine (données ouvertes DILA, Licence Ouverte Etalab 2.0)

Les dossiers de plus de 2 ans sont supprimés automatiquement.
